# OMML Structural Audit — ASR submission

Date (UTC): 2026-10-22. Scope: manuscript/build/manuscript_final.docx, manuscript_inline.docx.

## Method
- Unzipped word/document.xml; counted m:oMath elements; scanned all w:t (visible text) and m:t (math text) nodes for LaTeX residue and ASCII-math fallbacks.
- Equations are generated by scripts/build_docx_omml.py (latex2mathml -> docx-equation OMML) from manuscript/build/manuscript_final.md via split_math(); inline builder reuses the same add_segments().

## Results
- manuscript_final.docx: 117 m:oMath objects. Visible text: 0 "$", 0 LaTeX commands (\xxx), 0 "{{placeholders}}", 0 "*" chars, 0 ASCII math fallbacks (eps_theta, ||..||, bare ^T in text, 10^7 in text).
- manuscript_inline.docx: 117 m:oMath objects; same zero-residue result; figure/table captions also routed through OMML segments.
- Two literal "^" inside m:t are the m:acc accent character for \hat{n} (renders as n-hat in Word/LibreOffice) — valid OMML, not corruption.
- Equations are true Word equation objects (m:oMath), editable in Word's equation editor.

## LibreOffice rendering quirks found and fixed
- `(x)^{sup}` with plain parens dropped the base content -> templates use \left( ... \right)^{sup}.
- `\arg\min` corrupted -> `\text{arg min}_{...}`.
- `\mathrm{yr|deg|rad}` and other multi-letter \mathrm rendered letter-spaced -> `\ \text{yr}` / `\text{...}`.
- `~` -> `\approx` (verified renders as approx symbol).
- Stray LaTeX `\\approx` (double backslash) emitted literal "approx" -> fixed to single backslash.

## Residual non-math underscores (intentional, not math)
Identifiers such as source_id, n_quasar, n_pulsar, sigma_obs, p_mismatch appear as CSV/config column names and code schema in text and tables — documented data schema, not mathematical symbols.

Verdict: PASS.
