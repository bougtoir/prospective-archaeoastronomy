# Reproducibility report

## Scope
Everything in this repository is generated by `make all`:
`setup` -> `test` -> `simulate` -> `summarize` -> `figures` -> `tables` -> `manuscript-results` -> `qc`.

## Determinism
- master_seed = 20260924 (configs/default.yaml).
- Per-replication seed = master_seed + 7919 * replication_index; independent of scheduling/order.
- All Monte Carlo outputs in results/*.csv are bitwise reproducible under the same config.
- No randomness sources outside numpy Generator.

## Traceability
- Every number in manuscript/main.md is a {{placeholder}} resolved from manuscript/values.json,
  generated by scripts/manuscript_values.py from results/summary_*.csv.
- qc/numerical_traceability.csv maps each placeholder -> value -> generating script.
- qc_audit.py fails on missing values, uncited figures/tables, uncited references,
  unsubstituted placeholders in the built manuscript.

## Machine-precision checks (unit tests)
- Noiseless single-source sets recover N0 to numerical precision.
- Single landmark (n<3) produces no valid solution (p_invalid = 1).
- Redundant partial loss keeps reconstruction; robust estimators beat LS under mismatch.

## Data provenance
- Raw catalogue snapshots in data/raw/ (ICRF3 K-band, ATNF pulsars, Gaia DR3 bright subset).
- data/acquisition_ledger.csv records URL, UTC timestamp, bytes, sha256, access terms.
- Simulation results do not depend on catalogues: synthetic populations only; catalogue
  section is descriptive context.

## Environment
- Python 3.10, numpy/scipy/pandas/matplotlib/pyyaml; python-docx optional for .docx.
- No GPU, no network dependency for the core pipeline (catalogue fetch degrades gracefully).
- Full run: ~7.1e5 replications, ~50 min on 2 vCPU.
