# prospective-archaeoastronomy

Deep-Time Celestial Reference Networks for Reconstructing Terrestrial Orientation —
a reproducible Monte Carlo study targeted at *Acta Astronautica*.

## Reproduce

```bash
make setup   # pip install -e .[dev]
make all     # test -> simulate -> summarize -> figures -> tables -> manuscript -> qc
```

`make all` regenerates every result, figure, table, manuscript value, and QC
report from code under `configs/default.yaml` (fixed master seed). No manual
numeric insertion: manuscript numbers come from `manuscript/values.json`,
generated by `scripts/manuscript_values.py`.

For a fast smoke run: `python3 scripts/run_simulations.py --quick`.

## Layout

- `src/proarch/` — geometry, populations, encoding, degradation, noise,
  misidentification, robust reconstruction (LS / Huber / RANSAC), chirality,
  information cost, architectures M1–M7 plus the M1b direct-axis landmark
  benchmark (`direct_axis` flag), Monte Carlo engine, catalogue IO.
- `configs/default.yaml` — frozen analysis protocol.
- `scripts/` — run_simulations, summarize, figures, tables, catalogues,
  manuscript build, QC audit.
- `results/`, `figures/`, `tables/` — generated artifacts.
- `manuscript/` — `main.md` (placeholder-driven), `values.json`,
  `references.bib`, Acta guide audit, cover letter, highlights, declarations.
- `qc/` — numerical traceability, reference audit, reproducibility report.
- `handoffs/` — per-phase status artifacts.
- `data/` — raw catalogue snapshots + acquisition ledger (public data only).

## Key scenario assumptions (declared, not measured)

Source usability Weibull time constants, per-class secular direction drift
rates, mirror-ambiguity probability, and catalogue ID bit-width are scenario
parameters (see `src/proarch/degradation.py`, `simulation.py`,
`info_cost.py`, and Table 2 of the manuscript). They are varied across
sensitivity grids rather than treated as physical measurements.
